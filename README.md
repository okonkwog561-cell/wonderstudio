# WonderStudio — Personal Cartoon Creator

A free, static starter website for planning original cartoon videos. It runs in a browser and does not need a server, account, API key, or build process.

## How to use
1. Extract the ZIP.
2. Open `index.html` in a browser, or upload the files to a static hosting service that supports HTML/CSS/JavaScript.
3. Enter a story topic, choose characters and style, then select **Generate original script & scenes**.
4. Copy the plan or download it as a text file.
5. Use the scene plan with video/image tools and a video editor; then upload finished videos manually.

## Important limitations
- The YouTube link is only stored as a reference. This website does not download, watch, transcribe, or analyze the linked video.
- Script generation currently uses a built-in local template. It is not connected to a generative AI service.
- It does not generate rendered video, voices, or images, and it does not upload or publish to YouTube, TikTok, or Instagram.
- Real AI generation requires a suitable service/API and usually API credentials; automatic publishing requires official platform APIs, account authorization, and compliance with each platform's policies.
- No tool can guarantee views, earnings, or monetization approval.
- Create genuinely original work and use assets/music you have rights to use. Do not copy another creator's video and merely swap characters.

## Files
- `index.html` — page structure
- `styles.css` — responsive styling
- `app.js` — local script/storyboard planner
